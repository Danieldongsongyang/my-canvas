# Studio 第一阶段预留系列和剧集模型

Studio 短漫剧模块第一阶段的数据模型预留 `StudioSeries` 和 `StudioEpisode` 边界，但 UI 先保持最小可用形态：创建一个短漫剧项目时默认生成一个系列和 Episode 01，看起来仍像单项目单集工作流。完整多剧集管理、跨集复用面板、剧集列表和 LumenX 相关复杂组件迁移放到 MVP 后继续完善。

**Considered Options**

- 第一阶段只做扁平 `StudioProject`，后续需要多集时再重构。
- 第一阶段完整迁移 LumenX 的系列页、剧集列表和跨集资产管理。
- 数据模型先预留系列和剧集，第一阶段 UI 只暴露单项目单集。

**Consequences**

这个选择为短漫剧的跨集角色、场景、道具和画风一致性留下稳定边界，避免后续多集能力上线时重洗核心数据结构。同时它避免第一阶段被完整剧集管理拖慢；复杂多剧集交互应作为 MVP 后待办单独推进。
