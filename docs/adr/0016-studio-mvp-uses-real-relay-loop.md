# Studio MVP 跑通真实 relay 最小生成闭环

Studio 短漫剧模块第一阶段不只迁移静态界面和手动编辑能力，而是必须通过当前登录态、可用模型和用户态 AI relay 跑通一个最小生成闭环：剧本解析、角色/场景/道具草稿、用户确认或手动修改、R2V 分镜或镜头 prompt、至少一次图像或视频候选生成，并把结果回填到 Studio 本地项目数据。

**Considered Options**

- 第一阶段只做 Studio 壳和手动编辑，等界面迁完后再接真实生成。
- 第一阶段就接入真实 relay，但只做最小闭环，把完整任务队列、批量重试、组装导出放到 MVP 后。

**Consequences**

这个选择会更早暴露 relay 请求格式、模型参数、媒体引用和结果回填问题，减少 UI 迁完后才发现接口不匹配的返工。AI 结果必须可手动编辑，AI 失败也不能阻塞 Studio 继续使用；完整视频任务队列、批量重试、组装导出等能力作为 MVP 后待办继续完善。
