# 生成和导入成功即进入素材库

第一阶段中，素材库就是代码里的 asset，是用户成功生成、导入或上传后的共享媒体资产集合；它不是只有用户选中或手动保存后才进入的精选库。Studio 候选媒体和 Canvas 节点媒体都应表现为对 asset 的引用关系，Studio 和 Canvas 不各自拥有独立的媒体文件体系。

**Considered Options**

- Studio 和 Canvas 各自拥有独立过程媒体，只有用户主动保存后才进入素材库。
- 所有成功生成、导入或上传的媒体都进入本地素材库，Studio 和 Canvas 保存 asset 引用关系。
- Studio 和 Canvas 直接互相引用对方的候选媒体或节点媒体，不通过素材库统一。

**Consequences**

这个选择更符合常见 AI 创作产品的用户预期：生成过的图片或视频应能在素材库、生成记录或资产视图中找回。素材库需要支持来源、项目、收藏、标签、精选、未使用等筛选，以免生成历史和精选素材混成一团；删除 asset 时也需要检查 Studio 和 Canvas 引用，避免仍被项目使用的媒体被误删。
