# Studio 候选引用保留到显式移除

Studio 候选媒体是素材库 asset 在 Studio 项目中的候选引用关系，不是可以按时间或选中状态自动清理的临时缓存。只要候选图、候选视频或候选音频仍然记录在 Studio 项目、镜头、角色、场景或道具中，即使用户当前没有选中它，也必须保留这条候选引用，并保证对应 asset 不被误删。

**Considered Options**

- 未选中的候选引用按时间、容量或清理动作自动删除。
- 只有被用户选中的候选引用保留，未选中的候选引用视为可清理。
- 只要候选引用仍在 Studio 项目记录中，就保留到用户显式删除候选、删除镜头、删除 Studio 项目或执行明确的 Studio 清理动作。

**Consequences**

这个选择让用户可以回头查看和重新选择旧候选，符合短漫剧生产中“抽卡、比较、回退”的工作方式。实现上，生成链路应先创建 asset，再把 asset id 和必要使用上下文写入 Studio 候选引用；删除候选引用只解除 Studio 关系，不等于删除素材库中的 asset。真正需要保护的是 asset 删除动作：如果 asset 仍被 Studio 或 Canvas 引用，应提示影响并阻止默认硬删。
