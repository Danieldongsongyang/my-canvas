设计思维
在编码之前，先理解上下文，并坚定地选择一个大胆的美学方向：

目的：这个界面解决了什么问题？谁在使用它？
基调：选择一个极端方向——极致极简、极繁混乱、复古未来、有机/自然、奢华/精致、趣味/玩具感、编辑/杂志风、粗野主义/原始感、装饰派艺术/几何感、柔和/粉彩、工业/实用主义等。有众多风格可供选择，可将这些作为灵感，但最终需要设计出一个忠实于所选美学方向的作品。
约束：技术要求（框架、性能、无障碍）。
差异化：是什么让这个设计令人难忘？人们会记住哪一点？
关键：选择一个清晰的概念方向，并以精准度执行。大胆的极繁和精致的极简都同样有效——关键在于有意识的设计意图，而非强度。

然后实现可运行的代码（HTML/CSS/JS、React、Vue 等），要求：

生产级且功能完整
视觉上引人注目且令人难忘
具有凝聚力的美学观点
每个细节都经过精心打磨
前端美学指南
重点关注：

字体排印：选择美观、独特且有趣的字体。避免 Arial 和 Inter 等通用字体；选择能提升前端美感的特色字体——出人意料、富有性格的字体选择。将一款引人注目的展示字体与一款精致的正文字体搭配使用。
色彩与主题：坚持统一的美学风格。使用 CSS 变量保持一致性。大胆使用主色与锐利强调色的搭配，优于畏首畏尾的平均分布调色板。
动效：使用动画实现效果和微交互。对于 HTML 优先使用纯 CSS 方案。对于 React，在可用时使用 Motion 库。聚焦高冲击力时刻：一次精心编排的页面加载（使用 animation-delay 实现交错呈现）比零散的微交互更能带来愉悦感。使用滚动触发和出乎意料的悬停状态效果。
空间构成：突破常规的布局。非对称性。重叠。对角线流动。突破网格的元素。慷慨的留白或有控制的密集感。
背景与视觉细节：营造氛围和深度感，而非默认为纯色。添加与整体美学相匹配的上下文效果和纹理。运用创意形式，如渐变网格、噪点纹理、几何图案、分层透明度、戏剧化阴影、装饰性边框、自定义光标和颗粒覆盖层。
永远不要使用通用的 AI 生成美学，例如过度使用的字体族（Inter、Roboto、Arial、系统字体）、老套的配色方案（尤其是白底紫色渐变）、可预测的布局和组件模式，以及缺乏特定场合特征的一刀切设计。

以创意方式进行诠释，做出真正为具体场景设计的出人意料的选择。没有两个设计应该是相同的。在浅色和深色主题、不同字体、不同美学风格之间变化。永远不要在不同迭代中趋同于常见选择（例如 Space Grotesk）。

重要：让实现复杂度与美学愿景相匹配。极繁主义设计需要包含大量动画和效果的复杂代码。极简或精致的设计则需要克制、精准，以及对间距、字体排印和微妙细节的仔细关注。优雅来自对愿景的良好执行。
